| Роль                    				| Права роли                                                                                          																																													| Группы пользователей                            															|
| ----------------------------	| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------	| -------------------------------------------------------------------------------------	|
| cluster-admin           			| Полный доступ ко всем ресурсам в кластере.                                                         																																								| system:masters (например, для администраторов платформы Kubernetes) 	|
| namespace-reader        	| Доступ только на чтение ресурсов в конкретном namespace. Может просматривать Deployment, Pod, Service и другие ресурсы, но не изменять их. 											| developers, support (для отладки и мониторинга)  											|
| namespace-developer  	| Доступ на чтение, создание, обновление и удаление ресурсов в конкретном namespace. Может создавать и редактировать Deployment, Pod, Service и другие ресурсы. 		| developers                                      																		|
| secret-viewer           			| Доступ только на чтение секретов (Secrets) во всех namespaces. Для пользователей, которым нужно знать конфигурационные данные, но не менять их. 									| security, auditors                              																		|
| resource-quota-manager	| Доступ на управление ResourceQuota в конкретном namespace. Для управления ограничениями ресурсов.   																											| platform-engineering                            																|
